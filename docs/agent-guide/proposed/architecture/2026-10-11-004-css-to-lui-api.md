# 004 — Migrate remaining CSS to the LUI typed-prop API

Status: **approved for execution** (user-directed follow-up to 003).
Ground truth: the three classification audits
`003-assets/review-css-overlay-api.md`, `review-css-core-api.md`,
`review-css-theme-api.md` — per-rule tables live there; this doc is the

## Goal

Every stylesheet rule that a view can express through LUI typed props or a
shared recipe moves there; the stylesheet converges to tokens, runtime-state
decorations, animations, and test/imperative hooks. Web rendering stays
pixel-aligned to master; gpui gains the same structure for free.

## Rules

- Test-first where the migration changes behavior; per-surface 1280x900
  light+dark captures vs app.logseq.com for the touched surfaces.
- Migrated rules are **deleted**, never left as "fallback"; the
  `audit-unstyled-tokens.md` "CSS purge" section is appended per batch.
- `~style_class` keeps only app-semantic/e2e classes; `.lui-*` internals are
  renderer-owned (`platform/web/src/lui.css`) — never targeted.
- Dynamic classes (`ls-dialog-<name>`, `cp__settings-<key>-cnt`) stay as
  hooks; only their declarations migrate.
- Runtime `data-*` state attrs (renderer-set) stay styled; view-driven
  `selected`/`data-selected` migrate to `selected`/`*Background` props.
- Gates per batch: `dune build js_app test gpui/drive_test.exe`, 2009-check
  `test_main.js`, `dune runtest`, `npm run css:build`, browser spot-check.
- Commit the gpui registration removal together with its CSS deletion.

## Leftovers (do NOT build CSS machinery for)

`margin` (~40 rules — biggest single gap; candidate `Margin*` schema
addition or restructure to parent `~gap`/`~padding`), `flex-wrap`,
`hover-fg`/`hover-border`, `text-decoration`, `list-style`, `font-family`,
`position:sticky`, `transform`/`transition`/`@keyframes`, pseudo-elements,
`:focus-within`/`:has`/`nth-child`, group-hover descendant reveals,
`@media`/container queries, scrollbar, `-webkit-app-region`, `mask-image`,
`field-sizing`. These stay in the stylesheet as decoration/hooks unless a
prop is added later.
