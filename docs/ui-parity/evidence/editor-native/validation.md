## Failure and repair

Native editing accepted text, text selection, cursor movement and undo, but
showed no caret. The native service incorrectly advertised host-painted
rich-text carets. The SDL host's hidden extension sink does not paint such a
caret; only standard native inputs have their own caret. Enabling the existing
measured Edit_view overlay first restored a layout rectangle, but still no
paint: its legacy CSS color fallback was absent from the native app snapshot.
The shared color now also falls back to the app foreground; existing web
caret/primary-text overrides keep priority.

A separate real host-boundary test exposed device/logical pixel mixing:
scale 2 returned x40/h48 instead of logical x20/h24. Caret rectangles and origins,
editor height, and pointer hit requests now cross the boundary in the correct
units. The production typed overlay scales its logical lengths exactly once.
No LUI dependency edits, invalidation workaround, or standard-input change.

Test-first failures are retained in native-caret-red.txt,
native-caret-paint-red.txt and native-caret-scale-red.txt. Native host tests mount
actual Edit_view and execute copied production Host_requests, rather than
reimplementing its calculations. The bridge stub only records outbound replies
without opening any graph. Tests cover nonzero origins, backing scales 1/2,
model-offset hit testing, editor height, actual painted fills in light/dark,
and removal when the measurement frame clears.

## Validation and limitations

- Native executable, Melange UI and tests build; native-host, contracts and host
  suites pass. Shared UI suite: 2119 checks, 0 failures.
- Fresh isolated browser checks also pass when run serially (2/2); the recorded
  concurrent failure still requires investigation.
- Current Vite bundle's focused creation/focus E2E passes.
- Browser spacing passes. The property browser check timed out once during
  page creation in a concurrent two-file run, then passed alone. This is
  recorded, not erased or called a fully green parallel suite.
- Native production tests establish scale 2 calculations and dark-theme paint;
  actual desktop capture here is scale 1/light, not a macOS/high-DPI device test.
- Remaining: caret blink/thickness, pointer-to-caret placement, wrapped/atomic
  and bidirectional text, IME/candidate geometry, title editing, complete
  selection/history/clipboard/indent/drag paths, and web overlay interception.
  No entire editor feature area is fully verified.
- A later observation found the previous publication fixture title displayed
  Long Pagepa after a shortcut attempt. Hidden-property shortcut semantics are
  therefore explicitly unverified; a successful checkbox pointer mutation
  does not establish correct selection/chord handling.
